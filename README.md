# 🥊 Stickman Game

A 2D action game built with **Unity and C#**, focused on responsive combat, movement mechanics, animation-driven attacks, and defensive abilities.

This project is being developed while learning Unity game development, with an emphasis on building gameplay systems, understanding the underlying code, and improving the game step by step.

## 🎮 Features

### Player Movement

* Horizontal movement and directional control.
* Jumping and aerial movement.
* Air dash mechanics.
* Movement restrictions during attack combos for better combat control.

### Combat System

* Combo-based attacks.
* Animator-driven attack sequences.
* Attack transitions and input handling.
* Player combat state management.

### Defensive Mechanics

* Shield/block system.
* Hit reactions and blocking animations.
* Player health management.

### Animation

* Sprite-based character animations.
* Animator state transitions.
* Animation-driven combat behavior.

## 🛠️ Built With

* **Game Engine:** Unity
* **Programming Language:** C#
* **Input Handling:** Unity Input System
* **Animation:** Unity Animator
* **Version Control:** Git and GitHub
